YAESU FTM-500DR Repeater

Repeater how-to

POWER8Repeater RX (Receives) on SUBCHANNEL and Tx (transmits) on MAIN
RPT ARS25Choose the Rx on Suchannel, Tx on the Main. No RPT ARS, choose SQL TYPE and SQL FREQUENCY
RPT SHIFT26Activate Repeater: DX (upper button) + FUNC Dial + Power. Deactivate same way.
SQL TYPE45
TONE SQL FREQUENCY46To display the battery power during operations: GM (upper button) + FUNC Dial + Power. Doesn't work in X-Band Repeater mode.
