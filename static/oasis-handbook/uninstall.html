Factory Reset / Uninstall

Undo everything the setup scripts installed — without deleting your data

scripts/remove-oasis.py undoes everything the setup scripts installed: it stops, disables, and removes all OASIS services, deletes OASIS-managed system files, and strips the OASIS blocks from config.txt (DRA-Pi, CM4Stack, and the DS3231 RTC overlay). 

python3 scripts/remove-oasis.py            # dry-run — shows what would be removed, changes nothing
python3 scripts/remove-oasis.py --check    # report what OASIS state is present
python3 scripts/remove-oasis.py --apply    # perform the teardown
sudo reboot                                # drop the config.txt overlays
ℹ

It never deletes downloaded data. Maps, the FCC database, ZIMs, and vendored wheels are expensive (often impossible) to re-fetch offline, so the teardown leaves them. It lists those paths with their sizes so you can remove them by hand if you want a fully clean slate. It also leaves apt packages (chromium, rtl-sdr, gpsd, …) installed.

✓

Run the dry-run first — it’s the safe way to see exactly what --apply will touch before committing.
