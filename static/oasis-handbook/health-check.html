Health Check (doctor)

A headless check that mirrors the browser setup page — confirm a deployment over SSH

scripts/doctor.py is a headless health check that mirrors every verification the browser setup page performs — useful for post-deploy confirmation over SSH when no browser is available, or as part of CI. Run it right after setup to confirm the deployment is healthy before going to the field. 

python3 scripts/doctor.py                     # run all checks
python3 scripts/doctor.py --core             # core checks only
python3 scripts/doctor.py --json             # machine-readable output
python3 scripts/doctor.py --host 192.168.1.10   # check a remote OASIS instance

Core checks (set the exit code)

CheckWhat it verifies
Server reachableGET /health returns 200 on port 8083
FCC index presentEN.idx exists and reports a callsign count
Maps directorymaps/ contains at least one .pmtiles
Disk spaceReports free space on the SD card / disk

Exit codes: 0 = all core checks pass (optional services may still warn) · 1 = one or more core checks failed. Optional-service checks (GrayWolf, Kiwix, Winlink, APRS API, Web SSH, RTL-SDR blacklist, GrayWolf tiles) are warnings only and don’t affect the exit code.

✓

Scriptable: python3 scripts/doctor.py --json | … parses core_ok for a CI gate.
