The Setup Menu

setup-oasis.py — the front door for a Pi deployment

On a Pi, setup-oasis.py is the front door. It is a grouped checkbox menu that delegates to the individual install-* / enable-* scripts, so each stays the single source of truth. Tick what you want; it runs the matching scripts in order, pulls in prerequisites, and asks for your password just once. The pre-checked items give you a working field station out of the box — dashboard, APRS, web terminal, service controls, and Wi-Fi fallback. Re-run the menu anytime to add features.

[ screenshot — setup-oasis.py grouped checkbox menu in the terminal ]
ℹ

Version-aware & idempotent. Every installer installs when absent, upgrades when newer, and keeps what you have otherwise — never downgrades. It picks the newest source (apt vs the bundle) and the packages for your OS version, so an older USB bundle can’t clobber a newer package.
