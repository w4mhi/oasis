The Dashboard

Dashboard Tour

The single page every operator opens — status, services, and every tool

The dashboard at http://<host-ip>:8083 is the home screen for the whole suite. It is one page, refreshed live, that shows the health of the station and links to every tool. It works on a phone as well as a desktop.

Header

Across the top: a clock, the Wi-Fi pill (current SSID or AP: OASIS), the GPS/GNSS card, and the System Monitor cards (CPU, RAM, disk, temperature, IP, uptime), all colour-coded and updated every 30 seconds.

Service strip

A row of cards, one per companion service (GrayWolf APRS, APRS Stats API, Winlink, Kiwix, Web SSH, OpenWebRX). Each shows live status — green when up, red when down, grey when not installed — and, if you enabled service controls, START / STOP buttons so you never have to SSH in.

APRS live table

When APRS is running, the APRS LIVE table lists heard stations with callsign, last-heard time, speed, altitude, and comment; clicking a callsign opens the live map focused on that station. See Stations & History.

Utilities · forms · reference

The lower navigation groups every static tool: the calculators, net logger, ICS forms, FCC lookup, offline maps, Repeater Book, and the whole reference library — including this handbook.
