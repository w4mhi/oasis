OpenWebRX SDR

Optional receive-only SDR web UI for spectrum monitoring

OpenWebRX+ is an optional receive-only SDR web UI on port 8073 for spectrum monitoring and multi-mode decoding. It is off by default, and since 3.92.0 OASIS does not manage it: no service card, no health tile, no dot on the panel, no dongle assignment. Install it, start it and point it at a tuner yourself. The reason is honesty — OpenWebRX picks its SDR inside its own Admin → SDR devices UI, so anything OASIS recorded about that choice described a decision it had not made and could not carry out.

[ screenshot — OpenWebRX+ waterfall and receiver UI (not enabled on the reference box) ]
python3 services/openwebrx/install.py    # installs OpenWebRX+ on :8073
sudo systemctl start openwebrx          # run it (off at boot, deliberately)
sudo systemctl stop openwebrx           # give the dongle back
⚠

The RTL-SDR feeds one consumer at a time. OpenWebRX, the APRS SDR feed, ADS-B and the weather watch all want a dongle, and whoever starts first keeps it. OASIS cannot see which tuner OpenWebRX took — so when you start one of its own SDR services while openwebrx is running, it says so and offers to stop it first. That prompt is the only place OpenWebRX still appears in the UI.

ℹ

Time matters for the SDR decoders — set up GPS time sync so FT8 / WSPR windows line up without internet NTP.

Troubleshooting

SymptomCause & fix
:8073 refusesOpenWebRX is optional and off by default. Install it (services/openwebrx/install.py), then sudo systemctl start openwebrx. There is no dashboard card to check — ask systemd: systemctl is-active openwebrx.
It starts, but shows no SDR deviceAnother consumer holds the dongle. systemctl is-active aprs-sdr-feed dump1090-fa oasis-nwr names it; stop that one, or give OpenWebRX a second dongle in its own Admin → SDR devices.
Starting it killed the APRS feedExpected — both want the one RTL-SDR. They are mutually exclusive on a single dongle.
It grabbed the dongle again after a rebootSomething enabled it at boot. sudo systemctl disable openwebrx — OASIS installs it disabled precisely so it cannot win that race.
