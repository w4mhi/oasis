Audio Hardware

The DRA-Pi-Zero sound card, its RX LED, and the RGB Cooling HAT

Beyond a USB interface (DigiRig, AIOC) or an RTL-SDR, OASIS has dedicated support for the DRA-Pi-Zero I²S sound card and the Yahboom RGB Cooling HAT.

DRA-Pi-Zero sound card

The MastersCommunications DRA-Pi-Zero (Wolfson WM8731 I²S codec) is GrayWolf’s radio interface on many builds. Configure it with: 

python3 scripts/enable-dra-pi.py            # auto-detects the phase
python3 scripts/enable-dra-pi.py --dry-run  # preview the config.txt changes first

It runs in two phases. Before reboot (card absent) it edits /boot/firmware/config.txt to load the WM8731 overlay and free the I²S bus (backing the file up once). After reboot (card present) it applies the ALSA mixer routing — the critical Input Mux = Mic, capture gain, TX path — and persists it with alsactl store.

⚠

Run --dry-run first to review the config.txt diff before it writes — this edits a boot file. A reboot is required for the codec to appear.

DRA-Pi RX LED

GrayWolf keys GPIO 12 (the red TX LED) during transmit but has no carrier-detect output, so the DRA-Pi-Zero’s green RX LED (GPIO 16) stays dark while packets decode. enable-dra-rx-led.py installs a lightweight daemon that pulses the green LED on each newly decoded APRS position packet. 

python3 scripts/enable-dra-rx-led.py            # install + enable dra-rx-led.service
python3 scripts/enable-dra-rx-led.py --self-test  # blink the LED 5× and exit

RGB Cooling HAT

For a Yahboom RGB Cooling HAT (PWM fan + status OLED + RGB LEDs), a small daemon drives the fan from CPU temperature and shows live stats on the OLED: 

python3 scripts/install-rgb-cooling-hat.py           # install + enable the service
python3 scripts/install-rgb-cooling-hat.py --check   # report status
python3 scripts/install-rgb-cooling-hat.py --disable # remove it

It enables I²C, installs the apt deps, confirms the HAT on the bus (0x0d fan/RGB MCU + 0x3c OLED), and installs the daemon as a systemd service. The daemon itself needs no internet (it has an inlined SSD1306 driver).
