Hardware & Deployment

Panel & Kiosk Displays

On-device displays — the CM4Stack panel and a small-screen touch dashboard

OASIS is browser-served, so any device is a display — but for an all-in-one box you can also drive an on-device screen: the M5Stack CM4Stack panel, or a compact small-screen / touchscreen kiosk.

Small-screen / kiosk dashboard

small-screen/index7.html is a compact, touch-friendly dashboard tuned for small panels (a 3.5–7″ Pi screen or the CM4Stack panel), with large tap targets and a condensed status strip. Configure the kiosk automatically: 

python3 scripts/enable-autostart-pi.py --7inch

--7inch implies --with-browser, sets the kiosk URL to http://localhost:8083/small-screen/index7.html, enables touch, and sets the window to 800×480.

CM4Stack panel

For an M5Stack CM4Stack (Pi CM4) with the built-in ST7789V2 SPI panel, GT911 touch, and GPIO fan, the on-device panel display is configured with: 

python3 scripts/enable-cm4stack.py             # auto-detect the setup phase
python3 scripts/enable-cm4stack.py --dry-run    # preview config.txt changes

It runs in two phases and requires a reboot between them: first it patches config.txt and sets headless boot (exit code 10 = reboot required); after reboot it builds the GT911 touch-fix overlay and installs oasis-panel.service. Exit codes: 0 done · 10 reboot required · 1 error.
