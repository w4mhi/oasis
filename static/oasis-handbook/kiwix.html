Kiwix Wikipedia

Offline Wikipedia and reference ZIMs served on the LAN with kiwix-serve

Kiwix serves offline snapshots of Wikipedia and other reference content through a local web server on port 8081. When the grid is down, it turns a ZIM archive on the Pi into a searchable, browsable encyclopedia for every device on the LAN — medicine, survival, repair, radio theory — with no internet.

[ screenshot — the Kiwix reader serving a Wikipedia ZIM (not enabled on the reference box) ]
ℹ

Kiwix is optional and off by default. Its dashboard card shows NOT INSTALLED or DOWN until you install it and load a ZIM — that is normal, and the rest of OASIS works without it.

Installing the server

The installer sets up kiwix-serve and its systemd unit (/etc/systemd/system/kiwix.service). It picks its source automatically: if create-oasis-offline.py staged the package in offline-packages/kiwix/ it installs with no network; otherwise it downloads from kiwix.org. 

python3 services/kiwix/install.py              # install latest kiwix-serve on :8081
python3 services/kiwix/install.py --version 3.8.2
python3 services/kiwix/install.py --zim-dir /mnt/ssd/zim   # keep ZIMs on external storage

Getting Wikipedia content

The ZIM archives are large and copyright-managed, so they are never in the repo — you fetch them once (online) and carry them to the field. The helper offers editions sized for a Pi: 

python3 services/kiwix/download-wikipedia.py                    # interactive picker
python3 services/kiwix/download-wikipedia.py --edition top-mini    # ~316 MB, 50K best articles (default)
python3 services/kiwix/download-wikipedia.py --edition simple-mini # ~447 MB, Simple English
✓

ZIM files are just data — drop any .zim (Wikipedia, Wiktionary, medical references, project docs) into the ZIM directory and restart the service to serve it. External SSD storage plus --zim-dir keeps the SD card small.

Once installed, control it from the dashboard’s Kiwix card (service controls give it START / STOP), or open it directly at http://<host-ip>:8081.

Troubleshooting

SymptomCause & fix
Card shows NOT INSTALLED Run python3 services/kiwix/install.py (or pick Kiwix in the setup menu), then reload the dashboard.
Installed but the card is DOWN / :8081 refuses The service isn’t running: sudo systemctl start kiwix. Check journalctl -u kiwix -e — the usual cause is no ZIM in the library.
Server is up but shows an empty library No ZIM loaded. Fetch one with download-wikipedia.py (or copy a .zim into the ZIM directory) and restart the service.
Ran out of disk pulling a ZIM Editions range from a few hundred MB to many GB. Use a smaller edition (top-mini) or point --zim-dir at an external SSD.
Search finds nothing inside a ZIM The archive’s full-text index may be missing. Re-download the ZIM (the indexed editions from the picker include search).
