Getting Started

Quick Start

Build the offline bundle on your computer, carry it to the Pi, run the guided setup

OASIS is offline-first, so the recommended path is to build a self-contained bundle on your everyday computer (macOS / Windows / Linux) and carry it to the Raspberry Pi on a USB stick. The Pi never needs internet.

⚠

Don’t git clone directly on the Pi for a full deployment. A clone gives you code only — you’d still need internet on the Pi to pull GrayWolf, Kiwix, the FCC database, and the rest. Build the bundle on your computer and carry it over.

  1. Clone on your computer. 
    git clone https://github.com/W4MHI/oasis-emcomm
cd oasis-emcomm
  2. Build the offline USB bundle. This downloads every offline asset (Python wheels, GrayWolf, Kiwix, RTL-SDR, webssh, Pat, FCC database, map tools) and assembles a self-contained oasis-offline/ folder. 
    python3 scripts/create-oasis-offline.py        # add --for-windows to bundle the Windows runtime
    Copy that whole folder onto a USB drive. See USB Bundle for details.
  3. Copy the bundle to the Raspberry Pi. Plug the USB into the Pi and copy the bundle into your home directory (e.g. ~/oasis-emcomm).
  4. Run the guided setup as your normal user — not with sudo: 
    cd ~/oasis-emcomm
python3 setup-oasis.py          # guided checkbox menu
    Tick the features you want; it runs the matching install scripts in order and asks for your password once. See The Setup Menu.
  5. Reboot so all settings and services come up cleanly: 
    sudo reboot
  6. Connect. If you ticked Auto-start on boot, OASIS is already running — open http://<pi-ip>:8083 from any device on the same network. Otherwise start it manually: 
    cd ~/oasis-emcomm
scripts/start-server.sh
✓

Truly offline. Flask, gunicorn, and psutil ship as pre-built wheels for every supported platform and Python 3.9–3.14. Only the one-time data downloads (FCC, maps, Wikipedia) touch the internet — do them on any machine and carry the result over.

ℹ

Fresh Pi? Flash the SD card, enable SSH, and install git first — it isn’t pre-installed on Raspberry Pi OS Lite. Then validate everything at home before going to the field. See Accessing OASIS.
