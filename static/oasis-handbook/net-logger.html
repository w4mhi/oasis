Net Check-in Logger

Log check-ins during a net and export CSV

The Net Check-in Log (tools/net-log.html) logs check-ins during a net — callsign, name, location, and traffic — plots them on an offline map, and hands the whole roster to an ICS-309 in one click. The log itself lives in this browser’s localStorage, so it survives a reload and a closed lid.

⚠

This tool works without internet, not without the server. It is served by Flask and calls back into it for four things: /api/lookup (FCC callsign lookup and autocomplete), /api/browse (enumerating your PMTiles map files), and /api/forms/save + /api/forms/list (Save to server / Restore). It also pulls MapLibre, PMTiles and the Maidenhead helper from server-absolute paths. Open the file straight off disk and the map, the lookup and the snapshots are all dead. What does keep working with the FCC feature absent: typing entries by hand, logging, sorting, inline edit and delete, Print, Export CSV, Import CSV and the ICS-309 handoff.

The net header

Fill the Net Details block before the first check-in — it is what the ICS-309 handoff uses to fill in the form’s heading.

FieldNotes
Net namee.g. ARES/RACES Net. Becomes the ICS-309 incident name, and seeds the filename when you save to the server.
Frequencye.g. 146.520 MHz.
Net controlYour callsign. Lands in the ICS-309 operator field and on every row as the receiving station.
Date (UTC)Auto-filled as YYYY-MM-DD UTC.
Map fileA dropdown of the .pmtiles files found in maps/, via /api/browse. This is the basemap the Map tab draws. If it reads (error loading files) the server is not reachable; if it is empty, add a PMTiles file and restart the server.

Logging a check-in

Type a callsign and the tool queries the offline FCC database on Enter, Tab or blur. On a hit it auto-fills Name, City, ST and Grid, marks them as filled, and jumps the cursor to Notes so you can keep listening. On a miss it drops a ranked suggestion list (a wildcard prefix search, closest matches first, capped at ten) — useful when a callsign came through the noise half-copied. Picking a suggestion re-runs the lookup and moves on to Name.

The check-in table has eleven columns:

ColumnNotes
#Sequence number. Deleting a row renumbers the rest by UTC order, so it stays 1–N.
UTCStamped HH:MMZ at log time. This is the stored value.
LocalDerived at render, 24 hour. Never stored — so a log carried to another timezone still reads correctly in both columns.
CallsignThe lookup key.
Name, City, ST, GridAuto-filled from the FCC record where one exists; all four remain editable.
TrafficA tick box; renders as Y.
NotesFree text.
(actions)edit and del per row.

Most columns sort on their header. edit turns the row into inline inputs — UTC, callsign, name, city, state, grid, traffic and notes, with Local staying read-only — and changing the callsign during an edit re-queries the FCC database. del confirms first.

Getting the log out

ButtonWhat it does
→ ICS-309The most valuable path off this page. It copies the whole log into the ICS-309 communications log and opens it in a new tab: net name becomes the incident, name plus frequency the net, the first and last check-in the from/to times, net control the operator, and every check-in becomes a message line reading name — city, state — notes — (traffic). It hands over through localStorage, so nothing goes over the wire and nothing is lost if the new tab is slow to open.
PrintOpens the browser print dialog on a print stylesheet — the map and the buttons drop out, the roster does not. This is your paper copy when the power budget says the screen goes off.
Export CSVNine columns: #, UTC, Callsign, Name, City, State, Grid, Traffic, Notes. Note there is no Local column in the export — UTC is the record.
Import CSVReads a CSV back in. Match the exported column format.
Save to serverWrites a timestamped JSON snapshot server-side, named from the net name and the date. Never automatic — it is an explicit click.
RestoreLists the saved snapshots and loads one back over the current log.
ClearEmpties the log.

The map tab

Two tabs sit above the roster: Check-ins and Map. The Map tab is a real MapLibre GL map reading your offline PMTiles basemap — the same tile stack as Offline Maps — with every check-in plotted as a labelled dot and a popup carrying the callsign. Positions come from the FCC record’s coordinates where one was found, and fall back to the Maidenhead grid square. The view auto-fits to the plotted stations, and the Fit button re-frames them at any time. A status line counts what was plotted and names anything skipped for having no grid.

✓

Pair it with FCC lookup to confirm a check-in’s name and location, and hand the finished roster straight to an ICS-309 for the after-action report.

Troubleshooting

SymptomCause & fix
Check-ins vanishedThe log lives in this browser’s localStorage. Use Export CSV or Save to server to persist it beyond one device.
Callsign lookup shows no APIThe FCC database feature is not installed on this box. Log by hand, or install it from the setup menu.
Map tab is empty / No .pmtiles files foundNo basemap. Put a .pmtiles file in maps/ and restart the server — see Offline Maps.
The map has no pinsCheck-ins need coordinates: either an FCC hit or a grid square. Add a grid per entry.
Can’t import a CSVMatch the exported column format; a stray header or delimiter will reject the row.
Nothing works when opened from a USB stickThe tool is not standalone. Reach it through the OASIS server (/tools/net-log.html), not as a file:// path.
