Accessing OASIS

Reach the dashboard from any browser — on your LAN or the Pi’s own hotspot

OASIS binds to 0.0.0.0 on port 8083, so any device on the same network reaches it in a browser at http://<host-ip>:8083. There is no app and no account — the operator’s existing browser is the only client.

On an existing network

If the Pi is joined to your Wi-Fi or LAN, find its address (the System Monitor IP row shows it, or use oasis.local when avahi is installed) and open http://<pi-ip>:8083 from your phone, tablet, or laptop.

In the field — the OASIS hotspot

For an activation or field event with no router, the Pi hosts its own Wi-Fi access point. With AP fallback armed, it prefers a known network when one is in range and raises the OASIS hotspot when none is. Other devices then join the OASIS Wi-Fi and open http://10.42.0.1:8083 (or http://oasis.local:8083).

⚠

Set up at home, deploy in the field. Complete the full setup — server, FCC database, GrayWolf, GPS, AP fallback — while the Pi has internet, validate it works, then take it offline. Sort out anything that needs internet before the activation, not on arrival.

⚠

OASIS has no authentication and runs plain HTTP by design — the right model for a trusted off-grid LAN or hotspot, the wrong one for the open internet. See Security.
