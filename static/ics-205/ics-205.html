BlockFieldInstructions
1Incident NameEnter the name assigned to the incident.
2Date/Time PreparedEnter date prepared (month/day/year) and time prepared (24-hour clock).
3Operational PeriodEnter the start date (month/day/year) and time (24-hour clock) and end date and time for the operational period to which the form applies.
4Zone / GrpEnter zone/group designator at the Communications Unit Leader's discretion.
4Ch #Channel number for incident radios programmed or cloned for this plan, or a reference line number.
4FunctionEnter the net function: Command, Tactical, Ground-to-Air, Air-to-Air, Support, or Dispatch.
4Channel Name / TalkgroupNomenclature or commonly used name for the channel or talkgroup (e.g. National Interoperability Channels per DHS FOG).
4AssignmentThe ICS Branch/Division/Group/Section to which this channel/talkgroup is assigned.
4RX Freq (N/W)Receive frequency: xxx.xxxx followed by N (narrowband) or W (wideband). For trunked systems, enter the system name across all frequency/tone fields.
4RX Tone/NACReceive CTCSS subaudible tone or Network Access Code (NAC) for the receive frequency.
4TX Freq (N/W)Transmit frequency: xxx.xxxx followed by N (narrowband) or W (wideband).
4TX Tone/NACTransmit CTCSS subaudible tone or Network Access Code (NAC) for the transmit frequency.
4ModeA = Analog, D = Digital, M = Mixed mode.
4RemarksRepeater locations, patched channels/talkgroups using links or gateways, etc.
5Special InstructionsCross-band repeaters, securevoice, encoders, PL tones, or other emergency comms needs. Include any special instructions for an incident within an incident.
6Prepared ByName and signature of the Communications Unit Leader. IAP page number and date/time prepared (24-hour clock).

Purpose: Provides all radio frequency or trunked radio talkgroup assignments for each operational period. Normally placed on the Assignment List (ICS 204).

Distribution: Attached to ICS 202 (Incident Objectives) and given to all IAP recipients. All completed originals go to the Documentation Unit.

PDF limit: The official FEMA ICS 205 form has 8 channel rows on page 1. This tool supports unlimited rows for planning purposes; only the first 8 are written to the PDF.
