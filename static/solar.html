How to Get Solar Data via Winlink
  1. Send a Winlink message to query@saildocs.com
  2. Leave the subject line blank
  3. Put only the following in the message body: http://hamqsl.com/solarrss.php
  4. Send the message, then wait a couple of minutes
  5. Make a second Winlink connection — the reply will be waiting with the XML attached
  6. Save the attachment to a known location, then use the Load File button below — or open the attachment, copy the full XML, and paste it into the text area
